🎯 프로젝트 소개

MPS(Music Performance Statistics)는 블록체인 기반 음원 통계 관리 플랫폼으로,
기업 회원이 등록한 음원의 사용 데이터와 리워드 현황을 투명하게 관리할 수 있도록 설계되었습니다.

스마트 컨트랙트를 통해 음원 재생 기록을 블록체인에 남겨 투명성을 확보

웹 클라이언트에서 기업은 음원을 등록하고 API를 호출하여 사용 현황 확인

백오피스를 통해 관리자와 기업이 손쉽게 데이터와 리워드 내역을 확인

📑 API 문서 (요약)

Auth

POST /auth/register 기업 회원 가입

POST /auth/login 로그인

GET /auth/me 내 정보 조회

Music

POST /music 음원 등록

POST /music/:id/play 음원 호출/재생 기록

GET /music/:id 특정 음원 상세 조회

Stats

GET /stats/usage/:musicId 음원 사용 통계

GET /stats/reward/:companyId 리워드 현황 조회

Blockchain

POST /chain/record 사용 데이터 블록체인 기록

GET /chain/verify/:txHash 트랜잭션 검증

🧑‍🤝‍🧑 팀 전체 회고

잘한 점

역할 분담을 명확히 해서 충돌 없이 빠르게 진행할 수 있었다.

스마트 컨트랙트와 API, 클라이언트, 백오피스를 통합적으로 연결하는 경험을 했다.

해커톤 일정 내에 배포까지 완료하여 실제 시연 가능한 결과물을 만들었다.

아쉬운 점

블록체인 연동 부분에서 테스트넷 환경 제약으로 트랜잭션 속도/가스비 이슈가 있었다.

클라이언트와 백오피스 디자인 일관성이 조금 부족했다.

배운 점

멀티 플랫폼(클라이언트/백오피스/블록체인) 환경에서는 초기 설계와 문서화가 핵심이라는 것을 깨달았다.

API 하나가 여러 클라이언트에서 재사용될 수 있도록 범용성을 고려해야 한다는 점을 배웠다.

🎤 최종 후기

MPS 프로젝트는 단순한 웹 서비스 개발을 넘어서 블록체인, API, 데이터베이스, 클라이언트를 모두 아우르는
풀스택 경험을 할 수 있었던 좋은 기회였다. 특히 스마트 컨트랙트와 실서비스 연동 경험을 통해
블록체인 기술을 실제 서비스에 접목할 수 있다는 자신감을 얻었다.

또한 협업 과정에서 역할 분담과 커뮤니케이션의 중요성을 다시 한번 체감했고,
다음 프로젝트에서는 더 정제된 문서화와 테스트 문화를 적극적으로 도입해야겠다고 느꼈다.
