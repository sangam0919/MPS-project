🎯 프로젝트 소개

MPS(Music Performance Statistics)는 블록체인 기반 음원 통계 관리 플랫폼입니다.
기업 회원이 등록한 음원의 사용 데이터와 리워드 현황을 투명하게 관리할 수 있도록 설계되었습니다.

스마트 컨트랙트로 음원 재생 기록을 블록체인에 저장해 신뢰성과 투명성 확보

웹 클라이언트에서 기업은 음원을 등록하고 API 호출로 사용 현황 확인

백오피스에서 관리자와 기업이 손쉽게 데이터와 리워드 내역을 조회

📑 API 문서 (요약)
Auth

POST /auth/register : 기업 회원 가입

POST /auth/login : 로그인

GET /auth/me : 내 정보 조회

Music

POST /music : 음원 등록

POST /music/:id/play : 음원 호출/재생 기록

GET /music/:id : 특정 음원 상세 조회

Stats

GET /stats/usage/:musicId : 음원 사용 통계

GET /stats/reward/:companyId : 리워드 현황 조회

Blockchain

POST /chain/record : 사용 데이터 블록체인 기록

GET /chain/verify/:txHash : 트랜잭션 검증

🎤 최종 후기

MPS 프로젝트는 단순한 웹 서비스 개발을 넘어 블록체인, API, 데이터베이스, 클라이언트를 모두 아우르는
풀스택 경험을 쌓을 수 있는 좋은 기회였다.

특히 스마트 컨트랙트와 실서비스 연동을 직접 경험하며 블록체인 기술을
실제 서비스에 접목할 수 있다는 자신감을 얻을 수 있었다.

또한 협업 과정에서 역할 분담과 커뮤니케이션의 중요성을 다시 한번 느꼈고,
다음 프로젝트에서는 더 정제된 문서화와 테스트 문화를 적극적으로 도입할 계획이다.
